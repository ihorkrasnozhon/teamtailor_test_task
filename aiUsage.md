First of all, I'd like to remind you that this app is the result of my time and effort. 
I read the Teamtailor API documentation and tried to create a user-friendly interface 
similar to the Teamtailor website. Naturally, private data such as responses or API keys 
was not disclosed or used as a prompt.

I used AI to speed up my workflow and ensure compliance with best practices, 
as I believe it's crucial to know how to use it. 
Below is a brief description of how I used Gemini AI:

My knowledge of application architecture standards is limited, so I used AI to 
refactor the codebase into a modular structure for better functionality, maintainability, 
and scalability.

I also used AI as a consulting tool to create centralized error handling middleware 
and a custom AppError class.

AI helped create Jest test suites and Axios mocks, as I'm not very familiar with this topic 
at the moment, but I understand that it's a crucial part and can't be completely abandoned.

AI was used to analyze logs and troubleshoot environment-specific issues, 
such as path mapping in tsconfig.json, run build process and API entity naming inconsistencies.
